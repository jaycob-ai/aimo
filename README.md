# AIMO

每天早上说一句「AIMO」，把当天的 AI 进展整理成一份能长期存档的简报。

它只写你自己电脑上的 Markdown 文件，不需要数据库，不需要服务器，不上传你的数据。

## 它做什么

1. 检索前一个自然日的 AI 新闻、人物观点、新工具、GitHub 项目和论文
2. 核对来源和日期，先给你一份候选清单
3. 你说「全部加入」，才写进本地文件

只展示、不落盘是默认行为，避免把没用的内容塞进你的文档。

## 安装

### 方式一：让 Codex 自己装（推荐）

在 Codex 里发这一句话就行：

```
安装这个技能：https://github.com/jaycob1202-eng/aimo/tree/main/aimo
```

装完新开一个对话，输入「AIMO」即可使用。

### 方式二：手动放文件

1. 打开 skills 目录
   - Mac：访达按 `Cmd + Shift + G`，粘贴 `~/.codex/skills`
   - Windows：文件资源管理器地址栏粘贴 `%USERPROFILE%\.codex\skills`
2. 在里面新建文件夹 `aimo`，把本仓库 `aimo/SKILL.md` 放进去
3. 确保路径是 `~/.codex/skills/aimo/SKILL.md`，文件名必须是大写的 `SKILL.md`
4. 重开 Codex，输入「AIMO」

## 使用

1. 用 Codex 打开一个用来放资料的文件夹
2. 输入 `AIMO`，等它给你候选清单
3. 回复编号挑几条，或者回复「全部加入」

产出两个文件：

- `AI行业进展.md`：公司/机构数据库与行业进展
- `每日热点.md`：每天的新闻、论文、工具与人物观点

## 常见问题

**说 AIMO 没反应？**

检查 `~/.codex/skills/aimo/SKILL.md` 这个路径是否存在，文件夹名和文件名都要对，然后重开 Codex。

**说完没生成文件，是坏了吗？**

没坏。只展示、不写入是设计如此，你确认之后才会落盘。

**需要联网吗？**

需要。它要去公开信息源检索并核验当天内容。
